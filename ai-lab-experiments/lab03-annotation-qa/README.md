# 实验 3：给标注员做"质检"（Cohen's kappa + 金标准埋点 + 双人仲裁）

对齐课程：10-18《人工标注流水线》（AI 数据工程实验工坊 · 实验 3）

## 背景

大模型对齐数据（偏好标注、SFT 演示）全靠人工标，标注员之间意见不一致是常态。只看"一致率"会骗人：
两个人都闭眼全标"正面"，一致率 100%，数据却毫无价值。Cohen's kappa 扣掉"瞎猜也能对"的部分，
只奖励**超出偶然**的一致；再配上"金标准埋点"（混在任务里的卧底题）定位谁在系统性犯错、
分歧项走"双人仲裁"——就是课程里标注质检的三件套。

## 运行方法

仅 Python 标准库，Mac / Linux 直接跑：

```bash
python3 lab03_annotation_qa.py
```

## 自查清单

- [ ] 代码一次跑通：一致率 85%、偶然一致率 50%、kappa = 0.70（"高度一致"档）
- [ ] 说出混淆矩阵里 9 / 1 / 2 / 8 四个格子的含义，以及 p_e = 50% 是怎么算出来的（两类各自的边际概率乘积再求和）
- [ ] 把 idx13 的 B 从 0 改成 1（一条分歧变一致），重跑：kappa 从 0.70 升到 0.80——用自己的话说出"kappa 只奖励超出偶然的一致"的含义
- [ ] 把 B 的 20 条标签全部改成 1 重跑：一致率还有 50%，kappa 却掉到 0.00——说出这个"kappa 悖论"的直觉（边际分布极端偏斜时，偶然一致率吞掉了一切）
- [ ] 金标准：A 只对 3/5 且错的全在分歧项，B 全对 5/5——说出为什么埋金标准能定位"谁在系统性犯错"，而 kappa 只能说"两人不一致"
- [ ] 仲裁：分歧率 3/20 = 15% < 20% 才走仲裁，仲裁后金标准 5/5——说出分歧率 > 20% 时为什么不该仲裁（指南本身有问题，回炉改指南）
