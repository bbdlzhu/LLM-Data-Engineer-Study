# 实验 1：揪出混进预训练数据的测试题（13-gram 污染检测）

**日期**：2026-10-10 ｜ **难度**：★☆☆☆☆ ｜ **用时**：约 30 分钟 ｜ **依赖**：仅 Python 标准库

## 背景

大模型评测作弊最常见的一招：测试题原文混进了预训练语料，模型"考前看过卷子"。GPT-3 的做法很朴素——把评测题切成 13-gram，和语料里的 n-gram 求交集，重叠率超 80% 就判污染。这个实验亲手实现这个检测器。

## 运行

```bash
python3 lab01_contamination.py
```

## 数据集

- `corpus`（代码内）：6 篇模拟的预训练文档。其中 doc4 原样收录了 q1 整道题（含答案解析）——典型的"刷题网站解析页被爬进语料"；doc5 是同一知识点的改写版；其余为干净文档。
- `benchmark`（代码内）：3 道模拟评测题，q2、q3 在语料里只有主题相关、没有原文。

## 运行结果

实际输出见 [运行结果.txt](运行结果.txt)：

```
评测题   最可疑文档     重叠率     结论
------------------------------------------
q1      doc4      100%    ⚠️ 污染
q2      doc1      0%      干净
q3      doc1      0%      干净
------------------------------------------
污染率：1/3
```

## 想一想

doc5 是 q1 知识点的**改写版**，13-gram 检不出它。但如果评测时模型"见过"的是改写版，算不算作弊？这就是"逐字污染 vs 释义污染"——n-gram 只能抓前者。抓后者要靠语义方法（比如 embedding 检索去重）。
