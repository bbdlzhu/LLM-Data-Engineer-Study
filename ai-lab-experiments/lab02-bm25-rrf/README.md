# 实验 2：亲手搭一个混合检索引擎（BM25 + RRF 融合）

- 日期：2026-10-17
- 对齐课程：10-17《RAG 检索增强生成》
- 难度：★★☆☆☆（进阶入门）｜预计用时：40 分钟

## 背景

RAG 的检索端很少只用一种检索器：BM25 擅长关键词精确匹配，稠密检索擅长语义匹配，两者各有盲区。
生产级做法是**混合检索**——两路并行召回，再用 RRF（Reciprocal Rank Fusion）把两份排名融合成一份，
最后进 cross-encoder 重排漏斗。

本实验把这套链路亲手实现一遍：BM25 按课程公式原样写（k1=1.2、b=0.75），
A 路用字符 bigram（细粒度精确）、B 路用单字（粗粒度召回），最后用 RRF 融合（k=60）。
生产级第二路是稠密检索（需要 embedding 模型），这里用粗粒度 BM25 代替——融合机制 RRF 是同一套。
